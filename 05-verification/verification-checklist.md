# Verification Checklist

## Personal AI Output Verification Checklist

Before using an AI-generated output, I will check the following:

1. **Identify the Content** — What information or claims does the AI output contain?
2. **Check Against the Source** — Is each important point supported by the original information?
3. **Check for Missing Information** — Has the AI filled gaps with assumptions?
4. **Check Accuracy** — Are names, dates, numbers, and other details correct?
5. **Check Relevance** — Does the output answer the intended workplace task?
6. **Check Structure** — Is the output clear and easy to understand?
7. **Human Review** — Have I reviewed the final output before using or sharing it?

## Verification Decision

## Key Learning

AI-generated information should be treated as a draft until it has been reviewed against reliable source information.
